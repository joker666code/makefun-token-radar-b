Which pre-token protocol is worth farming next?

Every protocol below records no token in the snapshot — that is the record, not proof it has none. Each is ranked by what its launch would be worth if its record stayed as it is, with the six steps to farm it — a Week 0 check of the record first, then five weekly steps. Implied values are this board's own claim, never a prediction that a token will launch, or when.

How the value is worked out — the whole model, in the open

implied = TVL × category multiple × momentum × seasoning × breadth × credibility

  • Category multiple. The median market-cap / TVL of the token-having protocols in the same category, shrunk toward the snapshot's global median when a category has few peers, then clamped to 0.05–0.80. No name is ever hard-coded: the multiples come from this snapshot's own figures.
  • Momentum. 1 + 0.4 × the 7-day TVL change, winsorised to −40%…+60%. A spike above +60% is capped and flagged — check it is not mercenary capital before you trust it.
  • Seasoning. 0.75 + 0.25 × age / 3 years. Older protocols with no token yet have survived longer without one; unknown age takes the 0.75 floor.
  • Breadth. +2% per extra chain, at most +8%.
  • Credibility. Starts at 1.00 and loses 0.03 for a missing 7-day change, 0.03 for a missing listing date, 0.02 for TVL under $10M, 0.02 for a single chain (floor 0.90). Thin or incomplete records are penalised, never rewarded — and nobody is dropped from the board for them.

Three lenses: Implied value ranks by the model above; Early movers ranks by momentum × youth, the protocols moving fastest while still young; Value density ranks by implied value per dollar of TVL, the protocols whose TVL converts most efficiently.
